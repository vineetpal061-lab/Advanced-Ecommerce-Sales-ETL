# 🚀 Advanced E-Commerce Sales ETL Pipeline

An automated, robust **Extract, Transform, Load (ETL)** pipeline built using Python and SQLite. This project processes raw e-commerce sales data, handles duplicates and missing values, calculates total metrics, and loads it into a structured relational database with execution logging.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Processing:** Pandas
* **Database:** SQLite
* **Logging:** Python Logging Module
